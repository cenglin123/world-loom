## 一、人设

> 人设不是标签集合，而是一套能解释”为什么这样想、为什么这样选、何时会改变”的生成模型。字段内容应形成因果链，并能用于预测选择、制造冲突或解释演化。

### 人物小传

> 用一段叙述把这个人的故事讲出来——不必面面俱到，写你觉得最关键的经历、性格的成因、驱动力是什么。自由文本，可先写后由 agent 协助填入结构化字段，也可由 agent 根据已有字段合成后交你校对。

### 形成机制

| 字段 | 内容 |
|---|---|
| 塑造性事件 | （真正改变过他的关键经历；只写事件，不写流水账生平） |
| 错误信念 | （他从事件中得出的片面结论；关于自己、他人或世界） |
| 自觉欲望 | （他以为得到什么就能解决问题，必须具体） |
| 深层需要 | （他真正需要理解、接受或改变什么；不等同于自觉欲望） |

### 当前稳定内核

| 字段 | 内容 |
|---|---|
| 核心价值排序 | （目标冲突时的优先级，如“姐妹安全 > 查清真相 > 门派名誉 > 自己性命”） |

| 默认策略 | （通常用控制、讨好、逃避、谈判、攻击等哪种方式解决问题） |
| 压力退化模式 | （资源不足或恐惧升高时，默认策略如何变形） |
| 认知盲点 | （哪类事实最容易被忽略或曲解） |
| 行为边界 | （正常状态下不愿做什么） |
| 越线条件与代价 | （什么冲突会逼他越线；越线后会失去什么、如何面对自己） |

### 身份矛盾

| 字段 | 内容 |
|---|---|
| 表面身份及其要求 | （公开身份，以及该身份要求他必须怎样生活） |
| 秘密自我 | （真正想要、害怕或必须隐藏的另一面） |
| 暴露代价 | （秘密被看见后会失去什么） |
| 逼迫选择的条件 | （什么事件会让两个身份无法继续共存） |

### 表达层

## 四、场景决策（写前动态生成，不在人物卡持久化）

> 每场由 Agent 根据人设、L2 记忆、关系和现场信息写入 `_准备_第M章.md`。人物依据自己的主观信念行动，不依据作者掌握的客观真相。
> 场景分主动/被动两类交替推进——**主动场景推事件，被动场景推人物**。不是每场都要两种都写，按本场性质选。

### 主动场景（角色追求目标）

- **Belief · 当前信念**：知道什么、误解什么、相信什么？
- **Desire · 本场目标**：希望本场结束时出现什么结果？
- **Intention · 当前意图**：已经承诺采用什么计划？
- **Obstacle · 障碍**：谁或什么阻止目标实现？
- **Tactic · 当前策略**：正在用什么手段改变对方或局面？
- **换挡条件**：失败到什么程度时换策略或放弃？
- **可接受代价**：为本场目标最多愿意失去什么？

> 主动场景应以**挫折或复杂化**收尾，而非干净的成功——干净的成功让下一场无处可去。

### 被动场景（角色消化后果）

- **反应**：对上一场结果的即时反应——生理层面的、来不及思考的
- **困境**：现在所有选项都不好，各自的代价是什么？
- **决定**：他选了哪条路？**这个决定成为下一个主动场景的 Desire**

> **人设演化发生在这里。** 角色不是在打斗中改变的，是在"反应→困境→决定"里改变的。
> 「决定」字段非空时，`scripts/check_maintenance.py` 会提醒复核演化记录——
> 这是把语义判断转成结构信号，让脚本能兜底。是否真的构成演化仍由 agent 判断。
