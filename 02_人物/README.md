# 人物

> 每个角色一份文件：`<角色名>.md`，人设→记忆→关系三层合一。格式见 [[02_人物/人物模板]]。

## 文件

- `人物模板.md`：新角色的骨架，每次复制一份
- `_索引.md`：角色清单 + 关系矩阵（由脚本生成，勿手改矩阵段）
- `relationships.json`：关系数据的唯一事实源
- `<角色名>.md`：各角色卡

## 创建流程

1. `python scripts/check_tags.py wizard <角色名>` — 从模板创建，输出**待完善清单**（含引导提示和示例值）
2. 与用户确认是否先写「人物小传」——自由叙述角色的经历、性格成因、驱动力。用户自己写，或 agent 根据对话中已透露的信息合成后交用户校对。小传是后续结构化字段的叙事原料，不必面面俱到
3. 逐条与用户确认结构化字段：形成机制 → 稳定内核 → 身份矛盾 → 表达层。小传在此过程中作为参考锚点
4. `python scripts/check_tags.py check` + `python scripts/check_tags.py _index` 更新索引

## 人物生成模型

人设不是标签集合，是一套能解释"为什么这样想、为什么这样选、何时会改变"的生成模型。六层结构：

| 层 | 作用 |
|----|------|
| 人物小传 | 叙事原料，自由文本 |
| 形成机制 | 塑造性事件 → 错误信念 → 自觉欲望 / 深层需要 |
| 当前稳定内核 | 价值排序、自我认同、默认策略、压力退化、认知盲点、行为边界 |
| 身份矛盾 | 表面身份 vs 秘密自我，暴露代价，逼迫选择的条件 |
| 表达层 | 外表、语言指纹、身体语言、注意力偏向 |
| 演化记录 | 追加制，禁止覆盖历史 |

设计方法见 [[00_世界观/_设计方法]]「反差身份设计法」。

## 记忆与关系

- **L2 情节记忆**：每场后追记，主观视角格式。同一事件在不同角色心里应留下不同判断
- **关系四格**：公开 / 隐藏 / 盲区 / 禁区，用 `python scripts/relationship.py set/update` 写入
- 卷末 `python scripts/relationship.py regenerate` 重建索引矩阵

回写工作由维护子代理执行，协议见 [[05_复盘/maintenance-executor]]。

## 工具

- `python scripts/check_tags.py check` — 四类标签完整性（所属/能力/等级/擅用）
- `python scripts/relationship.py show <角色名>` — 两两关系摘要
- `python scripts/recall.py <角色1> <角色2>` — 写前上下文召回
