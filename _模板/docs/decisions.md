# 设计决策记录

> 记"为什么选 X 而不是 Y"——**正文里读不出来的东西**。
> 世界观是什么、故事写到哪，别处都有（[[00_世界观/核心设定]] · [[简介]] · [[docs/CURRENT]]）；只有决策的理由没有别的容身处，丢了就真丢了。

## 怎么用

每次做出**有代价的取舍**时追加一条。判据：如果半年后的你（或一个新接手的 agent）会问"当初为什么这么定"，就该记。

不记：显而易见的选择、没有备选方案的决定、纯粹的偏好。

## 格式

```
### YYYY-MM-DD · 决策标题
- **决定**：选了什么
- **备选**：当时还考虑过什么
- **理由**：为什么选它——尤其是备选方案输在哪
- **代价**：这个选择放弃了什么、什么情况下需要重新考虑
```

## 记录

（待填写：如"为什么用限制性第三人称而非全知"、"为什么不设复活机制"、"为什么主角的错误信念定为 X"）

---

> 决策可以推翻，但**推翻要追加新条目说明理由**，不改写旧条目——和人物卡的演化记录同理。
> 旧决策连同它的理由一起留着，才能看出这个故事的判断是怎么演化的。
