## 文风注册表

> 每个角色在 frontmatter 中绑定 `style_register`，对应一个注册项。写前注入注册到上下文包；reviewer 检查角色对话/叙述是否与注册一致。**这是 reviewer 软阻断项**——属审美判断，但注册表提供了可对照的基线。

### 注册格式

每个注册含四个维度：

| 维度  | 说明                              | 示例（武侠注册）                       |
| --- | ------------------------------- | ------------------------------ |
| 称谓域 | 角色怎么称呼别人/怎么被称呼                  | 师叔/少侠/前辈/施主                    |
| 器物域 | 日常物件的叫法                         | 剑/刀/暗器/丹药/内力                   |
| 修辞域 | 比喻和意象的来源范围                      | 山水/四季/武术/佛道典故                  |
| 节奏域 | 句长偏好、对话与叙述比重、语气词习惯              | 简练、少感叹号、不押韵；战斗描写可适当铺陈          |
| 禁用  | 该注册中绝不应出现的词汇/句式（reviewer 可判定信号） | 先生/小姐/OK/搞定；魔法/圣光/卷轴；机械/计算机/星球 |

### 示例注册

> 以下三个注册是**某一种题材外壳下的写法示例**（这里取武侠/西域/宫廷）。方法与题材无关——换成西幻、仙灵、科幻、都市等（不完全列举）只需替换四个维度里的词表：称谓域、器物域、修辞域各按本书世界观填，禁用域填"本注册绝不该出现的他系词汇"。**开写前请按本书题材重写这几节，别直接沿用。**

#### `武侠`（示例，中原武林角色的通用注册）
- **称谓**：师叔/师伯/师兄/师妹、少侠/女侠、前辈/阁下、施主/贫僧
- **器物**：剑/刀/暗器/丹药/内力/轻功/穴位/经脉
- **修辞**：山水意境、四季变换、招式名（诗意或直白）、佛道用语
- **节奏**：简练、非必要不铺陈心理活动、战斗段落可细化、不在对话中长篇解释设定
- **禁用**：先生/小姐/伯爵/女士（西式称谓）；魔法/圣光/卷轴（西幻词汇）；OK/搞定/没办法（现代口语）；欧式长句；科技词汇

#### `西域`（来自西域或更西方的角色）
- **称谓**：大人/阁下/朋友、少主/主人
- **器物**：弯刀/骆驼/香料/药粉/异域乐器；**可以适当混用不同于中原的器物词**
- **修辞**：沙漠/绿洲/商路/星空/异域传说
- **节奏**：可稍繁复、可带翻译腔的短句结构
- **禁用**：中原特有的武侠称谓（师叔/少侠/施主）——除非设定中学过；现代口语
- **区分规则**：西域角色可以不知道中原的称谓/器物/修辞——**但中原角色不应该说出西域特有的词汇**，除非设定中学过。

#### `宫廷`（朝堂/贵族角色）
- **称谓**：陛下/殿下/大人/臣/下官/微臣
- **器物**：奏折/印绶/朝服/贡品/圣旨
- **修辞**：典故/历史/礼法/天象/君臣之道
- **节奏**：对话注重礼节层级、话中有话；可铺陈排比
- **禁用**：市井俗语/粗口；江湖切口；现代口语

#### `市井`（平民/商贩/底层角色）
- **称谓**：客官/掌柜/老兄/小弟/姑娘/婆婆
- **器物**：铜钱/扁担/瓦罐/短刀/锄头
- **修辞**：日常俗语、劳作场景、吃喝拉撒
- **节奏**：短句、口语化、节省修饰
- **禁用**：宫廷礼制用语（陛下/殿下/臣等）；文绉绉的典故引用；现代口语

### 使用规则

1. 每个角色绑定一个主注册（`style_register: 武侠`），可选一个副注册（如西域角色在特定场景切到 `西域`）
2. 叙事旁白默认跟随当前 POV 角色的注册——**以 POV 角色的语言习惯来叙述**
3. reviewer 检查时，**同场景不同注册的角色混写时，看其对话/叙述是否各自符合注册**——武侠角色不说西域词、市井角色不说宫廷礼
4. 新注册可随时增加——发现新的文风需求（如"仙侠""科幻"）时在注册表中定义即可
5. 注册的"禁用"项是 reviewer 的可判定信号——正文中出现了禁用词汇 = 文风漂移的客观证据
