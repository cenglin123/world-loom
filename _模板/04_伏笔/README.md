# 伏笔

> 伏笔登记表——open/closed/abandoned 状态机。**不登记 = 不存在 = 收不回来。**

## 文件

- `伏笔登记表.md`：全部伏笔登记（ID / 描述 / 埋下位置 / 触发条件 / 预计回收位置 / 回收方式与后果 / 实际回收位置 / 状态 / 备注）

## 怎么用

1. 写正文时埋下新伏笔 → 立刻登记，状态=open，并填好**触发条件**（什么事件将其激活）与**回收方式与后果**（如何兑现 + 留下什么）
2. 回收伏笔 → 状态改为 closed，填实际回收位置
3. 放弃伏笔 → 状态改为 abandoned
4. 每卷复盘检查 open 伏笔是否超期

## 工具

- `python scripts/check_foreshadowing.py` — 伏笔完整性 + 超期检查
- `python scripts/check_all.py` — 全仓检查含伏笔项
