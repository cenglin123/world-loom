# 文风样本库

用户给样本说"照这个写"时，样本原文放这里，总结出的规格登记到 `docs/style-locked.md`「文风模仿」段。**本目录是内容层，永不对外分发**（划分见 `scripts/layers.py`）。

广为人知的作家不需要这套流程——模型本就熟知，直接说"照金庸写"即可。这里只承接模型不知道的对象：用户自己的文风、小众作者、某个 UP 主的调子等。

## 吸纳流程

1. 样本原文（不改写、不拼接）放入 `<模仿对象名>/`——一个模仿对象一个子目录
2. 通读样本，把规格写进 `docs/style-locked.md`「文风模仿」段（格式与规则见该节）
3. 带 `[governance]` 提交——登记、更换、删除模仿对象都是改锁，须经用户确认
4. 之后写正文按登记执行；reviewer 复核时会对照样本判定调性是否跑偏

## 留存规则

样本**长期保留**——与方法卡素材的"过路不留"（见 `_方法/README.md`）相反。方法卡吸纳后是自足的操作指令，文风规格是有损压缩：复核"正文跑没跑偏"、日后重新总结、换锁前的比对，都要回到原文。
