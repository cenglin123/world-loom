# 大纲

> 主线一句话 → 分卷展开。以下六种模式提供不同入口：无论你已有完整世界观还是只有一个模糊想法，至少有一种能帮你找到故事的第一推动力。

## 文件

- `主线.md`：主线一句话 + 分卷阶段
- 各卷明细可在主线中展开，也可独立为 `第N卷_大纲.md`

## 大纲推导模式

下面六种模式各自需要一点素材作为起点。如果你连素材都还没有，先看**前置模式**。

### 前置模式：意象反推（什么都没有时用）

> 适用于手上只有一个画面、一句情绪、一个"我就想看到这样一幕"的场景。世界观是从这一幕**反推**出来的，不是先建好再往里塞故事。

**操作**：
1. 把那个意象**写具体**——不是"一场悲壮的战斗"，是"他举起剑时发现手在抖，而对面的人是他教出来的"
2. 追问：**要让这一幕成立，世界必须满足什么条件？** 师徒制度如何运作？为什么会走到刀兵相见？谁定的规矩？
3. 只保留让这一幕成立的**最小设定集合**——其余留白，写到时再补
4. 反推这一幕的**前因**（怎么走到这一步）和**后果**（这一刀之后会怎样）——前因是第一卷，这一幕是全书高潮或转折
5. 有了最小世界观和一条时间线后，转入下面任一模式继续展开

> 这条路径反向使用「规则即土壤」——先看到长出来的果实，再倒推需要什么土壤。适合从情绪或画面出发的作者。

以下六种模式适用于已有一定素材的场景。

### 模式一：关键设定失效展开

> 适用于已有较完整世界观的场景。故事不需要反派登场，只需要让世界某个重要系统突然坏掉。

**操作**：
1. 从 `00_世界观/核心设定.md` 的叙事层找出"这个世界最不能出问题的是什么"
2. 设计它失效的**具体事件**——越具象越好（不是"秩序崩塌"，是"圣泉喷出黑水"）
3. 推演失效的涟漪：谁第一个发现？谁最慌？谁想掩盖？谁从中获益？
4. 找到在这条涟漪链上被逼着行动的**那个人**——那就是主角，那个行动方向就是主线

**参考**：`docs/writing-style.md`「故事驱动法则」法则一/二。

### 模式二：矛盾原点推演

> 适用于已有物理层+社会层设定的场景。最深的故事不在战斗里，在世界的结构裂缝里。

**操作**：
1. 找到物理层与社会层的断裂处——资源如何分配？谁得谁失？干净的东西谁享用、脏活谁干？
2. 定位生活在这条裂缝上的**一个人或一群人**：他们每天面对什么？最怕什么？最想改变什么？
3. 设计一个打破现有平衡的事件——不用多大，只要足以让他们"不能再忍了"
4. 主线 = 从裂缝中站起来、往哪走、付出什么代价

**参考**：`00_世界观/_设计方法.md`「搭建顺序与贯穿理念」物理→社会→叙事三层的断裂推演。

### 模式三：势力碰撞推演

> 适用于世界中有多个势力/组织/国家的场景。势力之间天然有矛盾——找到那颗火星就够了。

**操作**：
1. 列出世界观中所有势力的**核心目标**和**底线**（什么绝对不能让步）
2. 找出两两之间目标冲突最不可调和的那一对
3. 设计一个事件让这对矛盾从"冷对峙"升级为"热冲突"
4. 主角可以是被卷入的人、想调停的人、或冲突双方各自的代表

**参考**：`00_世界观/_设计方法.md`「城镇选址评分法」势力博弈推演；`docs/writing-style.md`「矛盾来源」五种冲突类型可为势力碰撞提供方向。

### 模式四：代价螺旋

> 适用于世界观中有力量体系（魔法/功法/科技）的场景。力量不是免费的——让代价成为故事引擎。

**操作**：
1. 确定力量体系的**代价**是什么（精神熵增？寿命？自由？身份暴露？）
2. 设计一个场景：角色**付不起代价**了，或代价突然升级了
3. 推演角色如何应对：能换一种代价吗？能赖账吗？赖账有什么更糟的后果？
4. 代价从个人层面逐级外溢——先影响自己 → 牵连身边人 → 动摇整个系统的信用

**参考**：`00_世界观/_设计方法.md`「力量与代价体系」；代价体系对照见该文末表。

### 模式五：身份撕裂

> 适用于已有一个或多个人物雏形的场景。给角色一个必须藏起来的秘密——当秘密藏不住的时候，故事就开始了。

**操作**：
1. 定义角色的**表面身份**和它要求的**生活方式**
2. 定义角色的**秘密自我**——真正想要的是什么？为什么必须藏？
3. 设计**暴露临界点**：哪一天、什么事逼他必须在两个身份之间做选择？
4. 选择之后立刻产生代价——失去白天的世界？失去信任？失去自己？
5. 主线 = 秘密暴露 → 被迫选择 → 承受代价 → 在新的身份里找到平衡或继续撕裂

**参考**：`00_世界观/_设计方法.md`「反差身份设计法」四问框架。

### 模式六：边缘视角切入

> 适用于世界观宏大但找不到故事入口的场景。不要从世界的中心开始——从世界的边缘开始。

**操作**：
1. 找到世界结构中的**边缘位置**——地理边缘、阶级底层、被主流叙事忽略的角落
2. 找到最了解某个系统底层运作的**那个人**——不是最强者，是最接近问题的人
3. 当中心发生危机时，这个人**为什么第一个看出不对劲**（不是因为天赋，是因为他天天在跟这个系统打交道）
4. 他为什么**必须行动**——不是因为想当英雄，是因为如果他不查，锅一定扣在他头上

**参考**：`docs/writing-style.md`「故事驱动法则」法则三/四；亦见 `00_世界观/_设计方法.md`「底层视角法」。

## 模式选择指南

| 你的现状 | 推荐入手模式 |
|---------|------------|
| 什么都没有，只有一个画面或一种情绪 | 前置模式（意象反推） |
| 世界观已建成，不知道写什么故事 | 模式一（关键设定失效）或 模式二（矛盾原点） |
| 势力/国家/门派设了很多，不知道怎么产生冲突 | 模式三（势力碰撞） |
| 有力量体系但不知道怎么推进剧情 | 模式四（代价螺旋） |
| 有一个角色但不知道他的故事是什么 | 模式五（身份撕裂） |
| 世界太宏大，找不到具体的故事入口 | 模式六（边缘视角） |

## 叠加规则

模式可以组合，但**必须有主次**——否则会得到一个四分五裂的大纲。

**核心规则：一条主线只能有一个驱动源。** 选一种模式定主线骨架，其余模式降级为分卷工具或角色工具。

三个层级各司其职：

| 层级 | 用途 | 模式数量 |
|------|------|---------|
| **主线层** | 全书的核心张力，一句话能说完 | 只能有 1 种 |
| **分卷层** | 每卷的具体冲突，服务于主线推进 | 可用多种 |
| **角色层** | 单个角色的个人弧线，与主线交汇 | 可用多种 |

**示例**（三种模式不冲突，因为在不同层级）：

- **主线层**用模式一：圣泉喷出黑水 → 神权信仰崩塌（全书主线）
- **分卷层**用模式三：教会 vs 下水道工会的势力战（第二卷冲突）
- **角色层**用模式五：主角的秘密身份在第三卷暴露（个人弧线）

**冲突信号**：如果你发现两种模式都想当主线（比如既想写"设定崩塌"又想写"身份暴露"），先问自己——**哪一个坏掉，另一个才有意义？** 那个就是主线，另一个降为角色层。
