# 用户视角审计（对照使用手册.md）

> 审计对象：`使用手册.md`（下游用户视角，克隆后冷启动引导）
> 审计范围：仅 `.audit_dist/` 下文件；全部判定均给出仓库内证据（相对路径 + 关键原文摘录）
> 审计日期：2026-08-04

## 总评（一段话）

这套系统对"零基础新用户"的引导在**入口与主干流程上是闭环的**：克隆 → 说「初始化」→ `template.py init` 生成骨架 → CURRENT.md 给出下一步 → 手册按三种姿态给出可直接复制的提示词，绝大多数承诺（初始化、七种大纲推导、角色向导、文风模仿、四阶段工作流、世界建造分流、简介维护、体检）都有对应的真实文档与可运行脚本支撑，README → 使用手册 → AGENTS.md → 各子目录 README 的导航能互相指回，无死链。但**"系统会帮你守住什么"这五个安全承诺整体偏乐观**：其中四项（世界观治理、伏笔超期、时间线、独立审稿）的机械保障都比承诺的字面弱——脚本大多只校验"已登记的格式/留痕存在"，真正的语义守护依赖 agent 自觉执行 converge 协议；此外**「开新书」的"内容清空"覆盖不全**（正文、角色卡、卷复盘、文风样本不在 `template.py reset` 的模板清单内），是新用户第一个可能踩实的坑。整体判为"能走到动笔，但安全承诺需要打折扣理解"。

## 问题清单（按严重度）

- **[高] 「开新书」的"内容清空"覆盖不全** — 证据：`scripts/template.py` 的 `_templates()` 只枚举 `_模板/` 下文件，实测 15 个产物，无 `03_正文/` 章节模板、无角色卡模板、无卷复盘、无文风样本内容；使用手册.md:119 承诺"内容清空、机制保留"。修复建议：为正文/角色卡/复盘/文风样本补充模板（或让 `reset --all` 显式删除这些目录的未模板覆盖文件），并在手册中如实说明 reset 的实际覆盖范围。

- **[中] 「时间线不会倒流——章节时空一致性自动校验」言过其实** — 证据：`scripts/check_chapters.py` 只检测"同一 in_world_date 不同 location"（check_chapters.py:185-195），无日期先后倒序校验；`docs/audit-checklist.md:40` 声称"有时间戳的事件可机械校验"但脚本未实现。修复建议：在 check_chapters.py 增加 in_world_date 时序单调性检查，或将手册承诺改为"同一时刻同一角色不会出现在两个地点（自动）+ 时序倒流（人工审稿）"。

- **[中] 「核心设定改动必须走多轮独立评审」无法机械兑现** — 证据：`.githooks/commit-msg:46-62` 只校验 `[governance]` 标记字符串，不校验评审是否发生；"多轮独立评审"仅存在于 `05_复盘/reviewer-protocol.md` 流程描述。修复建议：至少在手册中区分"标记强制（防偷偷改）"与"评审流程（靠约定）"两个层级，不把后者描述成已强制兑现。

- **[中] 「正文有独立审稿」的独立性无法机械验证** — 证据：`.githooks/pre-commit:151-155` 对 `_审查后_` 缺失仅提醒不阻断，单 agent 自写自审可通过；独立性全凭 `docs/workflow.md:50` 与 `reviewer-protocol.md` 的协议约定。修复建议：在手册中如实描述"系统按流程设计为双 agent，留痕存在但独立性依赖工具自身约束"。

- **[中] 术语不一致：第三层到底是「张力层」还是「叙事层」** — 证据：使用手册.md:29 与 `_模板/00_世界观/核心设定.md`「三、张力层」用「张力层」；`00_世界观/_设计方法.md` 用「叙事层」并另列「角色层」（共四层）。修复建议：统一为同一套命名（建议与核心设定/手册一致的「物理→社会→张力」），或在 _设计方法 中注明对应关系。

## 手册之外发现的引导断点（如有）

1. **「体检」命令无显式脚本绑定**：使用手册与 README 都说"跟 agent 说「体检一下」，agent 会跑全部机械校验"，但 AGENTS.md 只把 `check_all.py` 挂在"完工必检"，没有"用户说体检 → 跑 check_all.py"的映射行。多数 agent 能自行对上，但属于"靠模型悟"而非"靠文档定"，建议在 AGENTS.md 信息导航补一行。

2. **`docs/CURRENT.md` 的「下一步」只在初始化时填充**：init 生成的 CURRENT.md 写死"初始化完成，尚无进行中的写作任务"，写作启动后若无 agent 主动维护会立刻过期；`docs/audit-checklist.md:56` 把"CURRENT.md 与实际状态一致"列为不阻断的观察项。新用户中途问"我到哪儿了"（手册 F2）得到的可能是过期状态，机制上无兜底。

3. **`example_world/` 中的 `核心设定.md` 是"半成品示例"**：其物理层填满、社会层/张力层留待填（example_world/核心设定.md:106-147），README 已声明是冻结快照、以模板为准。对先看示例再填模板的用户可能造成"物理层要填这么细？"的误导，但 README 边界说明到位，属轻微。
