# novel_world_one

> 一部正在创作中的长篇小说。

## 快速开始

1. 填写 `00_世界观/核心设定.md` — 物理层 → 社会层 → 张力层，三层逐项填写
2. 填写 `00_世界观/外围设定.md` 和 `01_大纲/主线.md`
3. 选定 `docs/writing-style.md` 中的视角、时态
4. 创建人物卡：`python scripts/check_tags.py wizard <角色名>`
5. 告诉 agent 开始写——它会引导你完成剩下的所有事

## Agent 协作

本项目依赖 AI Agent 运转。Agent 的操作准则、硬约束、四阶段工作流、完工检查清单——全部在 [AGENTS.md](AGENTS.md)。人类作者只需写设定和做审美裁决，其余交给 agent。
