# novel_world_one

> 一部正在创作中的长篇小说。

## 这是什么

一个面向 AI Agent 协作的长篇小说写作项目。文档体系按四阶段方法论构建（①宪法审查→②写前准备→③推进执行→④阶段复盘），主管 agent 依据 [AGENTS.md](AGENTS.md) 运行维护。

## 快速开始

### 人类作者
1. 填写 `世界观/核心设定.md` 和 `世界观/外围设定.md`
2. 填写 `大纲/主线.md`
3. 创建人物卡（参考 `人物/人物模板_*.md`）
4. 开始写作

### AI Agent
加载 [AGENTS.md](AGENTS.md) 后按四阶段工作流执行。——任何"写小说"类任务，不要直接写正文，先跑宪法审查（对照世界观+大纲）。

## 项目结构

```
├── AGENTS.md            # Agent 操作准则 + 导航（始终在上下文）
├── STRUCTURE.md         # 文档总索引
├── 世界观/              # 核心设定（locked）+ 外围设定
├── 大纲/                # 主线 + 分卷
├── 人物/                # 人设 / 记忆 / 关系（三层框架）
├── 正文/                # 按卷存放章节
├── 伏笔/                # 伏笔登记表（open/closed 状态机）
├── 复盘/                # 阶段性 converge 复盘记录 + reviewer 协议
├── docs/                # 项目文档（总览/叙述约定/陷阱/审计）
└── scripts/             # 工具脚本（changelog/agent_links/audit）
```

## 技术说明

- **文档格式**：Markdown（Obsidian 兼容）
- **质量门控**：`.githooks/pre-commit` 强制 AGENTS.md 同步 + 关键结构检查
- **版本控制**：Git（`.gitignore` 已排除 Obsidian 内部配置）

## 方法论来源

本项目的文档体系和工作流设计基于"AI 辅助小说写作的自动化方法论"——以知识库治理体系（converge 迭代收敛 + 宪法/软硬约束）为骨架，融合端木灵星传统写作技法和业界 AI 长篇写作实践。
