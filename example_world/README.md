# example_world · 模板初始化演示实例

> **这是什么**：用本仓库模板「初始化并填写一次」的**演示样例**，方便拿到模板的人（或在 Obsidian 里）直观看到"填好之后长什么样"。

## 边界（重要）

- **与任何在写作品无关**。内容（禹陆/季风气候体系等）是用规则法生成的教学 demo，不是某本小说的真实设定。
- **冻结快照**：可能滞后于 `00_世界观/` 等模板文件的最新 schema。**以模板为准**，本目录只作参考。
- **不是内容源**：真实写作内容一律放 `writing` 分支的 `00_世界观/` `01_大纲/` `02_人物/` `03_正文/`。**严禁**把本目录当作真书设定，也**严禁**把真书内容回填到这里——那才会造成多源污染。
- **不受治理钩子约束**：本目录不在 pre-commit 的 main 分支内容白名单检查范围内（它是有意为之的示例内容），也不在 `GOVERNANCE_FILES` 内。
