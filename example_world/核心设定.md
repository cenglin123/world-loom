### 地质与地理 + 气候机制（规则法生成 v1 · 待 converge）

> 这是社会层一切衍生品的物理根基：**地形→河流→雨带→粮仓→文明**。生成方法：先锁星球底层参数，再据科氏力 + 海陆分布，用行星气候规则推导风带、洋流、季风。**以下为规则法生成的初稿，`locked` 真正生效前应走一轮 converge / ultraverge 精审。** 命名均为占位工作名，可替换。

#### 0 · 星球底层参数（最底层 · 牵一发动全身）

| 参数    | 取值                   | 衍生影响                         |
| ----- | -------------------- | ---------------------------- |
| 恒星    | 单颗 G 型恒星（类太阳）        | 日照类地、有四季                     |
| 自转    | 顺行（西→东），日长约 26 小时    | 科氏力北半球右偏 → **大洋环流北顺南逆**、风带分异 |
| 自转轴倾角 | **≈30°**（大于地球 23.5°） | 季节剧烈 → **季风极强且极规律**（本世界招牌）   |
| 天然卫星  | 一颗大卫星                | 强潮汐，主宰沿海作息与航海（细节留外围设定）       |

> 倾角刻意取大值：季节越剧烈、海陆温差越大，季风越猛越准——一个被举世依赖、千年如一的季风，崩起来才够痛。这是张力层主线发动机的物理前提，**改倾角等于改主线，须 ultraverge。**

#### 1 · 海陆分布

坐标记法：经度 0–360°E、纬度 ±90°。

- **禹陆**（主舞台，北半球大陆）：约 5°N–58°N、40°E–160°E。一块从赤道伸到中高纬的大陆，南北跨度大 → 是季风的"热力发动机"。
- **南瀛海**（暖海）：禹陆以南的热带海洋（赤道带）。**季风的水汽源**，也是本世界气候的"控制杆"——其热状态的年际波动即本世界的厄尔尼诺式扰动（见张力层）。
- **赤环群岛**：约 5°S–5°N 的赤道岛链，南瀛海的南缘。
- **西洋 / 东洋**：禹陆两侧大洋。
- **南陆**：南半球中纬（25°S–55°S）的大陆，本书暂不登场，占位留 [[00_世界观/外围设定]]。

#### 2 · 山脉与河流

- **天脊山脉**：横亘禹陆中部、东西走向的巨大山墙（约 28°N–33°N 一线）。它是**季风的拦水坝**——把禹陆劈成"湿润的南"与"干旱的北"两个世界。
- **南向双河**：天脊南坡冰雪消融汇成两条大河，南流穿过季风带注入南瀛海 → 河谷 = 全星球最肥沃的粮仓。**粮仓同时吃两口水——季风雨 + 天脊冰川融水**，两口水各是一根可被掐断的命脉。
- **北向内流**：天脊北坡的水注入内陆盆地，形成正在退缩的咸湖 → 北境的干旱底色。

#### 3 · 风带（自转决定 · 常年固定）

| 纬度带 | 盛行风 | 说明 |
|--------|--------|------|
| 0–30° | 信风（东风带，吹向西） | 低纬主导 |
| 30–60° | 西风带（吹向东） | 中纬主导 |
| 60–90° | 极地东风 | 高纬 |

赤道附近有随季节南北摆动的**赤道雨带（ITCZ）**——夏季偏向受热半球。

#### 4 · 洋流（环流 · 常年固定）

北半球大洋环流**顺时针**，故对禹陆而言：

- **东海岸（东洋一侧）**：暖流向极地流（类黑潮）→ 温暖湿润、多台风、良港与海贸。
- **西海岸（西洋一侧）**：寒流向赤道流（类加州流）→ **冷岸沙漠 + 浓雾 + 上升流渔场**（雾岸渔民文化）。

#### 5 · 季风 —— 本世界的气候招牌（季节反转）

海陆比热差 + 大倾角共同驱动，禹陆南缘每年上演方向相反的两套风：

- **夏季 · 西南季风（雨季）**：禹陆内陆受热成低压，暖湿气流自南瀛海扑向南岸、撞上天脊倾盆而下 → 滋养季风带与南向双河粮仓。
- **冬季 · 东北季风（旱季）**：内陆冷却成高压，干冷气流自北境吹向海洋 → 旱季。

> 季风方向逐季反转，是这颗星球最鲜明的气候特征，也是文明的命脉时钟。

#### 6 · 气候带 → 社会层的土壤（下一步据此长出资源 / 势力 / 阶级）

| 区域 | 气候 | 社会层种子（待 §二展开） |
|------|------|----------------------|
| 季风带（禹陆南缘 + 双河河谷） | 湿热、雨季充沛 | 稻作密集、人口稠密、最富、文明心脏——**命系季风准时** |
| 天脊高地 | 高寒 | 隔绝、高地族群、大河之源（冰川） |
| 北境旱原（天脊以北） | 干旱草原 / 沙漠 | 游牧、逐水草、天然的南下压力源 |
| 雾岸（禹陆西海岸） | 冷岸沙漠 + 雾 + 渔场 | 孤立、向海、读潮读流的海民 |
| 东岸（禹陆东海岸） | 湿润温带、多台风 | 港口、海贸、风暴 |

> 这张表是社会层的"土壤"。下一步（社会层）只需让"水往低处流、雨落在哪里"自己长出经济与势力，不必另起炉灶。

## 三、张力层（社会层的裂隙 · 故事发动机）

> 本段是世界观的叙事潜力分析，不是故事正文。它回答的核心问题：**这个世界哪里会出事？**

### 这个世界最骄傲什么？

> 候选（规则法从气候推出的主线发动机；张力层属可受控扩展，可改 / 可与其他骄傲并存）：

**准时的季风，以及它供养的季风文明。** 千年来西南季风几乎同日而至，南向双河年年丰饶，季风带因此成为全星球最富庶、最自负的文明——它的历法、信仰、王权合法性全部押在"雨必如期而至"上。世界最骄傲的，正是这份"老天准时"的确定性。

### 可失效设定

> **物理法则（不可违反 · locked）**：季风成因机制、洋流环流方向、天脊拦水——这些在正文里不能被违反。
> **可失效的社会假设（主线燃料）**：**"季风千年如一日准时"**。

季风迟到数周、减弱数年，在物理上完全可能（南瀛海热状态的自然年际波动，即本世界的厄尔尼诺式扰动）——**它不违反任何物理法则，崩的是建立在它之上的社会假设。** 雨晚来、双河瘦了、冰川退了、粮仓欠收 → 北境游牧同样受旱南压 → 押注"雨必如期"的整套王权 / 历法 / 信仰随之动摇。这正是故事驱动法则一/二："关键设定就是用来失效的"、"世界最骄傲什么，就先让它坏什么"。

> 第二根命脉（可叠加增强张力）：粮仓还吃天脊冰川融水——**一次气候摆动可同时掐断"雨"与"雪"两口水**。

### 故事入口建议

> 故事驱动法则三：故事入口不该是最强的人，而是**最先读出异常的人**。候选：

- **雾岸的读潮读流者 / 渔季观测者**——洋流与海温先变，冷岸海民最早察觉南瀛海"不对劲"。
- **季风带的历法师 / 司天者**——靠"雨期推算"立身，第一个发现今年的雨晚了十二天。

这类角色身处"能看到系统异常却人微言轻"的位置，天然适合做主角或引线人。
