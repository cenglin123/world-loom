# 大纲

> 主线一句话 → 分卷展开。主线应从世界观叙事层「最骄傲的设定」的失效中长出。

## 文件

- `主线.md`：主线一句话 + 分卷阶段
- 各卷明细可在主线中展开，也可独立为 `第N卷_大纲.md`

## 如何推导

1. 读 `00_世界观/核心设定.md` 的叙事层——这个世界最骄傲什么？怎么让它坏？
2. 主线一句话从那个裂口中长出来
3. 故事驱动六法则反推分卷结构（见 [[docs/writing-style]]「故事驱动法则」）
4. 方法论细节见 [[00_世界观/_设计方法]]「叙事层」

## 工具

- `python scripts/check_all.py` — 死链 + 完整性校验
