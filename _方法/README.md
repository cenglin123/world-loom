# 方法卡库

一张卡 = 一套可照做的步骤。**不常驻上下文**——按需检索、按需展开。

```bash
python scripts/method.py find "不知道该写什么了"   # 不知道用哪张就先搜
python scripts/method.py show 长篇失速诊断         # 展开整卡
python scripts/method.py index --stage 世界观      # 只看某阶段的路由表
```

`_索引.md` 由脚本生成，是常驻的那一层：每卡一行（一句话 + tags）。
卡再多，常驻开销也只随卡数线性涨一点点；真正的正文只在命中时才进上下文。

## 卡片格式

```yaml
---
id: 组织建制法          # 唯一，等于文件名
阶段: 世界观             # 世界观 / 人物 / 大纲 / 正文 / 复盘
tags: [社会层, 组织]     # 归类
关键词: [学院, 门派]     # 术语——作者会怎么称呼它
症状: [组织内部没有矛盾]  # 原话——**求助者**会怎么描述这个问题
一句话: ...              # 进索引的那一行，必须自带判断力
落点: 00_世界观/...      # 产出写到哪个文件
相关: [城镇选址评分法]    # 双链，find --hop 1 会带出来
来源: [星白Knut/如何...] # 若这张卡来自外部素材（内部下沉的可省）
---
```

正文两节：**步骤**（编号，可照做）和**判据**（怎么算做完了）；
被素材修正过的卡末尾另有 **`## 沿革`**。

`症状` 是检索能不能用起来的关键。作者写卡用术语（"派系裂痕"），求助的人说的是
"组织内部没有矛盾"——词面检索跨不过这道鸿沟，只能靠写卡时把两套词都写进去。
缺这一栏 `method.py check` 会拦。

## 收录判据

**只收方法，不收素材。** 方法是"怎么做"，素材是"有什么"。
奇幻生物图鉴、骑士盘点、占卜方式一类的资料不进库——模型本身就知道一大堆，
收进来既重复又永远收不完，还会把索引撑坏。方法论才是稀缺的、模型不会主动照做的东西。

**常驻的判据不进库。** 像「故事驱动法则」这种任何时候都成立的短判据，留在
`docs/writing-style.md` 常驻。路由的意义在于筛掉当前用不上的东西——
永远用得上的东西没有筛的必要。

## 吸纳素材

```bash
python scripts/method.py ingest <素材文件或目录>
```

先查重，然后两条路：

| 查重结果 | 处置 |
|---------|------|
| **重复** | 和命中的卡逐一比较。**素材更优就用它改写那张卡**，否则丢掉素材 |
| **不重复** | 按上面的卡片格式直接开新卡 |

改完或新增完跑 `python scripts/method.py index && python scripts/method.py check`。

### 什么叫"更优"

**没有清单，你自己判断。**

写死一张评分表，遇到没预料过的素材就会判错；而这种判断本来就是模型擅长的。
`ingest` 只负责把素材和最相近的卡并排摆好——首位命中给全文，其余给一句话与判据，
够你比就行。

同理，"是否真的重复"也由你判断。BM25 分数只说明词面相近，不说明是同一套方法。

素材是**过路的**：判完就完了，不留台账。留下的只有卡本身——
它要么被改得更好，要么多了一张。
