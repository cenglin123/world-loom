# 反差身份设计法

反差被当成梗用就废了（"高冷总裁其实爱吃辣条"）。它真正的功能是**制造不可兼得**：
两个身份互相伤害、互相遮掩、互相逼迫，角色迟早得选一个，选就有代价。

## 步骤

1. **四问框架**：
   ① 表面身份是什么？
   ② 它要求他必须怎样生活？
   ③ 他真正想要的、害怕的、隐藏的是什么？
   ④ 哪天、什么事逼他必须在两个自己之间做选择？
2. **质量标准**：反差必须**逼出选择 + 有代价**——为什么藏？被发现失去什么？
   为什么不能永远逃避？litmus test：能想象出角色的行动与故事，而不只是一个梗。
3. **行为一贯性 + 伏笔**：反差前后须共享同一行为逻辑
   （"白天恶、晚上善"不成立，除非给出原因，如长期压抑的释放）。
   反转前**必须铺伏笔**，越平淡越精彩——别提前把身份摊开。
4. **张力-克制**：张力（深层矛盾欲望）+ 克制（维持表面、防暴露）
   → 平衡被意外打破 = 故事启动。主动追求：落差打破平衡；被动抉择：外部环境逼选。
5. **反差被看见**：冲突不来自多重身份本身，而来自身份在**错误的时间/空间被撞见**。

## 落点映射

| 四问 | 写进人物卡哪一栏 |
|------|-----------------|
| ①② | 表面身份及其要求 |
| ③ | 秘密自我 / 错误信念 / 自觉欲望 / 深层需要 |
| ④ | 逼迫选择的条件 / 暴露代价 |

行为一贯性由稳定内核 + L2 审查共同保证；身份暴露的伏笔登记到 `04_伏笔/`。
