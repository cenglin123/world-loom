# 城镇选址评分法

城市不是背景板，是**齿轮**。位置决定它靠什么活，靠什么活决定谁掌权，
谁掌权决定它内部裂在哪——一条链推下来，故事发动机就装好了。

## 步骤

1. **五维打分选址**：水源 / 能量网络位置 / 气候带 / 资源矿脉 / 食物自给
   → 推出城市规模与形态。例如"近能量汇集处但不在正中 + 稳定河源"
   → 一座数万人的圣城、宗门山城或要塞港。
2. **气候铁律**：别把繁复厚重的服饰搬到赤道。地理决定建筑、服饰、生活方式。
3. **一个核心势力 + 一个目标**（教会敛信徒、宗门收灵材、藩镇征税、财团圈资源）
   → 内部必有**裂痕**（纯信者 vs 借势谋利者、真传 vs 外门）。这不是 bug，是故事发动机。
4. **旧核新解**：取经典故事内核，用本世界规则重新解释。
   例如"猎人反成怪物"的母题，在力量会反噬的世界里可以是器官病变——
   于是主角同时是前执法者、被组织背叛者、和他毕生所猎之物的源头。

## 判据

- 说得出这座城**靠什么吃饭**，说不出就还没选址完。
- 第 3 步的裂痕必须能让两个具体的人站到对立面，抽象的"内部矛盾"不算数。
- 换任何题材外壳（西幻/武侠/科幻），一到四步不变——变的只有名词。
