# 力量与代价体系

能力清单人人会写，写完就发现力量泛滥、冲突失重。**代价才是设定的承重墙**——
力量稀缺比力量泛滥更抓人，因为稀缺才逼人取舍。

## 步骤

1. **能量网络**：把泡泡图（表面张力自动最小化能量）叠到地图 → 密集处能量循环快、
   强力量文明、战争频；稀疏处稳定；交界线易起风暴。可叠表层/深层两层
   （深层 → 特殊矿脉）。力量是"像湿度一样看不见的环境属性"，靠周围人/物的反应感知。
2. **底层逻辑**：给力量一条**可被角色理解**的原理。例如"力量 = 与未知沟通的桥梁，
   由意识驱动，你认为它什么样它就是什么样"。由此推出——
   **口诀**（法咒/心法/真言）= 维持干净意识的稳定器；
   **固化形制**（法阵/阵图/器械）= 把公式写死，好让庸才也能用；
   **天才** = 不需要这些中介，意识本就更纯粹。
3. **核心代价（必设）**：动用力量 = 意识对外熵减 → 付出**精神熵增**
   （注意力涣散、记忆失真、分不清真实与想象）。肉身 = 油箱，意识 = 引擎；
   过度动用伤器官，病变者可生异种。
4. 用"**运作原理 + 代价**"定义本书已有的每一种力量/功法。

## 判据

- 每种力量都答得出"用它要付什么"，答不出的删掉或补上。
- 代价必须**当场可见**。只在设定文档里存在、正文里从不发作的代价等于没有。
- 第 2 步的原理要能推出第 3 步的代价——推不出说明原理是装饰品。
