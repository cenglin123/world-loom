# 底层视角法

从王座看下去，世界是一张势力图；从排水口看上去，世界是一张**谁在替谁承担代价**的图。
后者才长故事——因为不公可以很安静，安静的东西必须被具体的人撞见才会爆。

## 步骤

1. **水从哪来 → 城市形态**：
   河流 → 沿河码头/渔市/染坊/商圈；
   井水 → 井是社区中心，谁控井谁控命脉；
   山泉 → 顺地势分层（上层饮头道泉、下层饮末水），**阶层自然生出**。
2. **脏东西往哪去 → 阶级显形**：神殿/宗门/学院/工坊的废水排进下城或地下水 = 现成冲突。
   卫生设施即阶级具象：上层用净化手段 → 平民用公用设施 → 最底层住的地方本身就是排污口。
3. **"干净是被分配的资源"**：不公不必靠反派宣言表达——水流方向、街道坡度、
   一个排水口的位置就够了。
4. **被忽视的职业 → 隐藏势力**：掏粪工/排水工/收尸队。下水道工会表面最底层，
   却握最全的地下地图（暗渠通王宫、教会、港口）→ 地下黑市、走私、强权。
   可推演"工会罢工第 1 / 3 / 7 / 15 天分别发生什么"。

## 判据

- 说得出这座城**谁在倒垃圾**，说不出就还只有上半截。
- 第 4 步至少要产出一个有名字的人，否则"隐藏势力"只是个词。
