# 地形生成法

手绘地图的问题不是画得丑，是画出来的东西**没有因果**——山脉凭空横着，河流不知从哪来，
于是后面所有"为什么这里有座城"都只能硬编。让地质规则先跑一遍，文明的位置就是推出来的。

## 步骤

1. **随机碎裂**取大陆/群岛雏形——想要群岛就碎得细，想要大陆就碎得粗。
2. 在雏形上随手画**地幔柱与对流方向**：板块挤压线 = 山脉，拉扯线 = 裂谷。
3. 先定**特殊地形**（沙漠/高原/盆地/冰原），避免后期冲突 → 天然推出地势走向。
4. 沿地势画**河流**主干 + 支流。河流多寡 = 文明密度与村落合理性。
5. 描一圈**浅海**收边。
6. **命名**（山脉/大洋/洋流）+ **绑定人群与资源**：谁守着矿脉，谁就吃冶炼与军械；
   谁占着林泽渡口，谁就吃商路与情报。经济、文化、战争自然衍生。

## 判据

- 每座城的位置都能用第 4、6 步解释——解释不了的说明是硬编的，挪或删。
- 地形先于势力。反过来做（先定势力再补地理）会得到一张处处巧合的地图。
