# 叙述约定

> 本文件定义文风倾向、可读性技法、故事驱动法则在本项目的落地形式。agent 写正文和 reviewer 审稿时以此为参照。
> 这些约定不锁进 [[00_世界观/核心设定|世界观]]（不是世界法则，是叙事工艺），可随项目迭代调整，走轻量评审即可。
> **硬参照子集在别处**：视角 / 时态 / 文风注册表三项是就绪自检与 reviewer 漂移检查的客观基线，定义在 [[docs/style-locked]]（受 `[governance]` 保护）。本文件保持轻量。
> 技法中可量化的阈值（三万字、首章 300 字等）在 [[docs/audit-checklist]] 中作为可核验检查项。
>
> **可读性技法的硬/软分类判据**：可机械化验证的阈值（字数/出现位置/次数统计）→ audit-checklist 硬检查；需人类审美判断的质感（节奏/张力/文风/是否"好看"）→ reviewer 软阻断 + 用户裁决。下方每条技法标注归属类别。

## 可读性技法（连载长篇）

以下是长篇连载在"抓住读者"上的通用工艺条目，作为本项目的 reviewer rubric 抓手。

### 开篇结构

- `[硬]` 300 字内主角出场、第一章抛出第一个冲突 —— `check_chapters.py` 统计
- `[硬]` 三万字内解决第一个主要矛盾 —— `check_foreshadowing.py` 字数+伏笔闭合
- `[软]` 前三章强化主角存在感、不要开头堆世界观设定 —— reviewer 软阻断

### 悬念与钩子

- `[硬]` 每章末尾必须留钩子（未解张力 / 提问 / 异动）—— 可由 reviewer 逐章检查"章末是否有 hook 标记"
- `[硬]` 伏笔要快速挖出来用掉 —— `check_foreshadowing.py` 已有时效检测

### 战斗描写（如适用）

- `[软]` 细节恰到好处、读者附身视角、适当议论说明原理、意境营造、服务于人物冲突 —— reviewer 软阻断

### 场景代入

- `[软]` 视觉 / 听觉 / 嗅觉 / 触觉立体呈现 —— reviewer 软阻断，"场景生动度"维度

### 矛盾来源（为大纲提供动力判断）

- `[大纲]` ①人物（争夺/情敌/护亲）②家族/地域/天地 ③种族 ④善恶对立 ⑤主角自身需求 —— 非检查项，是大纲规划工具

## 故事驱动法则（世界观→大纲指导）

以下六条法则解决"设定一大堆但写不出故事"的瓶颈。它们不替代上一节的可读性技法（那节管"写出来好不好看"），而是确保"设定本身有故事张力"。

| # | 法则 | 在大纲/写前合同中的落点 |
|---|------|---------------------|
| 1 | **关键设定就是用来失效的**——故事开头只需让世界某个重要系统突然坏掉 | `01_大纲/主线.md` 主线来源 |
| 2 | **世界最骄傲什么，就先让它坏什么**——第一枪打在世界最疼的地方 | `01_大纲/主线.md` 开篇约束 |
| 3 | **最了解系统的人最适合成为故事入口**——不要总让最强的人先发现问题 | `02_人物/<角色>.md` 角色定位 |
| 4 | **让设定主动接触人物**——不要让角色去"了解世界观"，让世界观的失效来撞角色 | 写前上下文包 |
| 5 | **多提问，少解释**——用角色的行动/反应展示设定，不用旁白 | reviewer rubric |
| 6 | **让人物别无选择**——关键情节中角色选择都在"都不好"中被迫选 | 写前达成断言 |

## 有限/无限框架的引导策略

> 本节独立于上方"故事驱动法则"——法则管"设定→故事张力"，本节管"Agent 用哪种姿态引导用户"。框架来源：以筠「有限设计与无限设计」番外二（基于 James Carse《有限与无限的游戏》）。

创作不存在唯一正确路径——同一个人、同一个世界观随时在两种模式间切换。Agent 的价值是识别当前模式并以对应策略辅助，而非替用户选择。

| 模式 | 核心驱动 | Agent 的正确行为 | Agent 不应做的事 |
|------|---------|-----------------|-----------------|
| **有限设计** | 交付作品为目标；快乐来自取舍、完成 | 反向约束——"最少需要多少设定？"；用故事驱动法则反推；保护用户不陷入无限扩展 | 指责用户设定不够多；用"你还没准备好"拖延推进 |
| **无限设计** | 持续建造为目标；快乐来自发现、延伸 | 苏格拉底式追问——帮世界跟用户抬杠；低摩擦提议"要不要写一小段试试？" | 追问"这对故事有什么用"；要求用户做取舍；推入有限流程 |
| **未确定** | 还在探索中 | 以"这里有两种玩法——"开头；3 轮后主动询问倾向 | 替用户做决定 |

**模式切换信号**（Agent 识别的自然时机，不强制提示）：
- 无限→有限：重复改同一设定 ≥5 轮、提到"读者""发表""写完"、对故事表达兴趣
- 有限→无限：写不动、翻看设定文件、正文停滞、砍设定后有遗憾

**切换对话模板**：
- 无限→有限："你这个世界里有矛盾越想越有意思——要试试把它写成小场景吗？不承诺什么，就看看能不能'动起来'。"
- 有限→无限："刚才砍掉的设定里有没有一直惦记的？回去玩一会儿，转一圈说不定找到新入口。"
