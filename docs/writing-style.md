# 叙述约定

> 本文件定义视角、时态、文风、端木技法在本项目的落地形式。agent 写正文和 reviewer 审稿时以此为参照。
> 这些约定不锁进世界观（不是世界法则，是叙事工艺），可随项目迭代调整，走轻量评审即可。

## 视角

（待选择：1-2 主角→第一人称；3-6 主角→限制性第三人称；>6 主角→POV。选定后在此写明，并标注该选择对人物记忆叙述的影响——第一人称 "我" 不能写别人内心。）

## 时态与叙述距离

（待选择：过去时 / 现在时？叙述者与主角的心理距离？全知旁白还是紧贴主角？）

## 文风倾向

（待填写：简练/华丽/口语化/半文半白？战斗描写的节奏偏好？对话与叙述的比重？）

## 端木技法在本项目的落地

以下技法来自 [[105【AIGC】/小说写作投稿技巧与经验汇总-端木灵星]]，作为本项目的 reviewer rubric 抓手。

### 开篇结构

- 前三章强化主角存在感、不要开头堆世界观设定
- 300 字内主角出场、第一章抛出第一个冲突
- 三万字内解决第一个主要矛盾

### 悬念与钩子

- 每章末尾必须留钩子（未解张力 / 提问 / 异动）——这是 reviewer "好看"维度的可判定信号
- 伏笔要快速挖出来用掉（不要埋了十章才提）

### 战斗描写（如适用）

- 细节恰到好处、读者附身视角、适当议论说明原理、意境营造、服务于人物冲突

### 场景代入

- 视觉 / 听觉 / 嗅觉 / 触觉立体呈现——作为 reviewer "场景生动度"的核验锚点

### 矛盾来源（为大纲提供动力判断）

- ①人物（争夺/情敌/护亲）②家族/地域/天地 ③种族 ④善恶对立 ⑤主角自身需求
