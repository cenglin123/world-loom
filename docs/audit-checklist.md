# 一致性审计清单

> 定期或复盘时运行 `python scripts/audit.py check` 做机械检查，然后按本清单逐项人工裁决。

## 机械检查项

- [ ] AGENTS.md / CLAUDE.md / GEMINI.md 同步一致：`python scripts/agent_links.py check`
- [ ] 文档内链无死链：`python scripts/audit.py dead-links`
- [ ] AGENTS.md 行数在 ~200 行以内：`python scripts/audit.py dead-links` 末端含行数报告

## 小说专项审计（agent 手动裁决）

### 世界观一致性
- [ ] `00_世界观/核心设定.md` frontmatter `locked: true` 未被非 ultraverge 修改
- [ ] 硬核心设定里的数值/地名/法则在近期正文中无违反
- [ ] 外围设定的增量补充未与硬核心冲突

### 人设一致性
- [ ] 所有角色的 `<角色名>.md` 人设段内核四维（欲望/恐惧/底线/应激）在当前章节中未被违反
- [ ] 有演化的角色：旧人设已标注"已演化" + 触发事件 + 时间点，演化逻辑自洽

### 记忆一致性
- [ ] 所有在场角色的 `<角色名>.md` 记忆段的 L2 条目已在当前卷结束后更新
- [ ] 每条新 L2 是主观视角格式（场景/我的行动/我的判断/情感轨迹/未解决问题/对他人看法变化）
- [ ] 无角色持有矛盾的 L2（两条记录对同一事实给出不同判断但无演化说明）

### 关系一致性
- [ ] `02_人物/_索引.md` 中的关系矩阵与各角色 `<角色名>.md` 关系段一致
- [ ] 近期有互动的角色对，其四格（公开/隐藏/盲区/禁区）已检查是否需要更新

### 伏笔一致性
- [ ] `04_伏笔/伏笔登记表.md` 中所有 状态=open 的伏笔未超期（未收超过 N 卷）
- [ ] 已收伏笔的回收方式与登记表中的预期一致（不一致但合理的记录理由）

### 时间线一致性
- [ ] 事件顺序无倒流（有时间戳的事件可机械校验；模糊时序的事件靠语义判断）
- [ ] 无角色在同一时间段出现在两个不同地点（除非世界观允许）

### 开篇结构（端木技法阈值）
- [ ] 前三章已强化主角存在感（未在开篇大段堆世界观设定）
- [ ] 首章 300 字内主角已出场、首个冲突已抛出
- [ ] 三万字内第一个主要矛盾已解决（`03_正文/第1卷/` 下章节总字数 ≤ 30000 时首个矛盾必须闭合）

### 结构与工具
- [ ] `docs/CURRENT.md` 与实际任务状态一致
- [ ] `docs/plans/active/` 无僵尸计划（超过 30 天未更新）
- [ ] CHANGELOG 无格式异常
