# AI 写作已知陷阱

> 本项目在写作过程中实际踩过的坑，给后续 agent 当检查清单。
> （初始化时为空——开始写作后 agent 遇到漂移/吃书/幻觉等情况，复盘后追加条目。）

## 尚未记录任何陷阱

开始写作后，每次复盘 converge 发现"本可以避免的问题"，就追加一条到这里。格式：

```
### YYYY-MM-DD · 场景 X
- **问题**：什么情况下的什么漂移
- **表现**：具体症状
- **原因**：为什么会发生（人设不够可操作？记忆没注入？世界观字段模糊？）
- **对策**：加入了什么约束/检查防止复发
```

## 常见 AI 写作问题类型（预设骨架）

以下是从方法论中预判的可能陷阱类型，实际遇到时填写：

- **标签化人格**：AI 用标签（"冷静""冲动"）代替可操作的行为边界，导致人物扁平
- **认知漂移**：角色忘了自己经历过的事（L2 记忆没正确注入或没正确回写）
- **世界观违反**：正文违反硬核心设定（力量体系数值冲突、地理矛盾、时序倒流）
- **伏笔腐化**：埋了伏笔忘了登记 → 登记表漏了 → 永远收不回来
- **关系僵化**：四格模型写了但没随剧情更新，关系卡在初始化状态
- **上下文衰减**：长篇到中后期，早期设定在上下文里被"挤掉"，agent 基于残缺信息写正文
