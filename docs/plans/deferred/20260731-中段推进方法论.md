# 中段推进方法论——长篇连载的张力维持与升级

## 0. 问题

现有 `01_大纲/README.md` 的七种模式（前置模式 + 六种推导模式）全部解决**"怎么开始"**——从设定/角色/意象中找到主线的第一推动力。

但长篇的真正难点不在开头，在中段：

- 第一卷冲突解决之后，第二卷写什么？
- 张力如何维持而不重复？
- 如何升级而不显得刻意加码？
- 读者对世界观的新鲜感耗尽后，靠什么继续？

这块目前**整个项目都是空白**——`docs/writing-style.md` 的可读性技法集中在开篇（300 字出场、三万字闭合首个矛盾），故事驱动法则解决的是"设定有没有故事张力"，都不覆盖中段。

## 1. 待设计的工具（初步构想，需实践检验）

### 1.1 升级螺旋

同类冲突逐级加压。核心问题是**加压的粒度**——每卷提升多少算合适？升太快后继乏力，升太慢读者流失。

待验证：
- 加压维度有哪些（对手强度 / 代价大小 / 时间压力 / 道德困境深度）
- 是否应该多维度轮换而非单维度线性升级
- 每卷升级幅度的经验阈值

### 1.2 代价累积

前面的选择开始收账。角色第一卷做的妥协，在第三卷变成必须偿还的债。

待验证：
- 收账时机——隔几卷收账最有效？
- 收账密度——一卷收几笔账不显得刻意？
- 与 `04_伏笔/伏笔登记表.md` 的关系——代价是否应该作为一类特殊伏笔登记？

### 1.3 视角轮换

换一个人看同一个世界，重新激活读者的新鲜感。

待验证：
- 轮换时机与频率
- 新视角人物的引入成本（读者需要多久接受一个新主视角）
- 与人物卡 L2 记忆体系的配合——多主视角下的记忆管理复杂度

### 1.4 世界扩张节奏

何时引入新地点/新势力/新规则，何时深挖已有的。

待验证：
- 扩张与深挖的配比
- 新元素引入的前置铺垫量
- 与"设定膨胀阻塞推进"（有限模式陷阱）的边界

## 2. 为什么 defer

以上四类工具的所有阈值（"每卷升级多少"、"隔几卷收账"、"轮换频率"）都是**经验参数**，不是可以从第一性原理推导出来的东西。当前项目零正文，硬编这些数字等于凭空捏造，且一旦写进文档就会被后续 agent 当作依据执行。

Bitter Lesson 视角：与其现在硬编先验参数，不如等有了真实中段体验，用 converge 复盘从实际卡点中提炼。
