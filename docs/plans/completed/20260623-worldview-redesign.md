# 世界观设定体系升级计划

> 基于以筠世界观设计系列 #1 #2 #6 的方法论，对 `00_世界观/` 和关联文件进行结构化升级。

## 现状

当前 `00_世界观/核心设定.md` 是扁平的三段填充模板："世界法则 / 善恶观 / 核心地理"。有用但缺少三层递进结构、代价体系、和"设定驱动故事"的机制。

## 以筠系列可吸收的关键原则

| 原则 | 出处 | 对本仓库意味着什么 |
|------|------|------------------|
| 规则即土壤，世界自己长 | 全系列 | 世界观不应是"属性列表"，应从底层物理规则衍生出社会，再从社会衍生叙事——**把三层结构写进模板** |
| 代价体系 | #2 #4 #5 | 每一种力量（魔法/功法/科技）必须有代价——**世界观新增"代价"字段**，check_chapters.py 可校验能力使用是否违反代价约束 |
| 关键设定就是用来失效的 | #6 法则一/二 | locked 不是铁板——**引入"可失效设定"概念**，区分"不可违反的物理法则" vs "前文明引以为傲、但故事里就要让它坏掉的社会设定" |
| 世界最骄傲什么就先让它坏什么 | #6 法则二 | 大纲主线应从这个"最骄傲的设定"的失效中长出来——**大纲模板新增主线来源指引** |
| 让世界的边缘先说话 | #6 法则三/四 | 故事入口不一定是世界中心——**人物创建向导新增"世界位置"提示**（上层/下层/边缘/中心） |

## 改动清单

### 1. `00_世界观/核心设定.md` — 三层结构化

从现状的三段扁平结构改为三层递进：

```markdown
## 一、物理层（底层规则，不可违反）
- 地质/地理：板块、山脉、河流（可引用以筠 #1 地图生成法）
- 力量体系：魔力/功法/灵力的**运作原理** + **代价**（以筠 #2 代价体系）
- 时间/空间法则

## 二、社会层（从物理层衍生）
- 资源分布 → 经济 → 势力
- 水源 → 城镇选址 → 阶级（以筠 #5 下水道视角）
- 组织/门派/国家

## 三、叙事层（社会层的张力 + 可失效设定）
- 这个世界最骄傲什么？（以筠 #6 法则二）
- 哪些设定是"可失效"的——不违反物理法则但可以在故事中崩塌
- 故事入口建议：边缘视角 vs 中心视角（以筠 #6 法则三/四）
```

每层增加 frontmatter 标记（`layer: physical|social|narrative`），便于脚本检测。

### 2. `00_世界观/核心设定.md` — 新增"代价体系"独立段

在物理层的力量体系段内，明确要求填写每种力量的代价。格式：

```markdown
### 力量体系：灵力

| 层级 | 能力 | 代价 |
|------|------|------|
| 初境 | 感知灵力 | 无 |
| 中境 | 外放灵力 | 施法后一炷香内无法再次调动 |
| 高境 | 灵力具象化 | 消耗寿元 |
```

`check_chapters.py` 新增检查：若角色使用某层级能力，对应代价是否在正文中被体现（软检查，非阻断）。

### 3. `00_世界观/外围设定.md` — 补设计工具指引

加一段引用以筠 #1 地图生成法和 #3 城镇选址评分法，供后续扩充外围地理时参考（不写进正文，仅作文档内指引）。

### 4. `docs/writing-style.md` — 融合以筠六大法则

在现有"端木技法"段后新增"以筠故事驱动法则"段：

```markdown
## 以筠·故事驱动法则（世界观→大纲阶段的指导）

1. 关键设定就是用来失效的 → 大纲主线应从"世界最骄傲的设定"的崩塌中长出来
2. 世界最骄傲什么，就先让它坏什么 → 主线第一枪打在世界最疼的地方
3. 最了解系统的人最适合成为故事入口 → 主角不一定是强者，可能是在最底层目睹异常的人
4. 让设定主动接触人物 → 不要让角色去"了解世界观"，让世界观的失效来撞角色
5. 多提问，少解释 → 用角色的行动/反应来展示设定，不用旁白
6. 让人物别无选择 → 关键情节中，角色的选择都应该在"都不好"中被迫选
```

### 5. `01_大纲/主线.md` — 新增主线来源指引

在"矛盾来源"段后增加：

```markdown
## 主线来源（以筠法则二）

主线应从世界观叙事层中"最骄傲的设定"的失效中长出来。

| 世界观最骄傲什么 | 怎么让它坏 | 对应主线方向 |
|---------------|----------|------------|
| （待填） | （待填） | （待填） |
```

### 6. `02_人物/人物模板.md` — 新增"世界位置"字段

在 frontmatter 增加可选字段：

```yaml
world_position: 上层  # 上层|下层|边缘|中心——该角色在世界结构中的位置
```

人物创建向导（`check_tags.py wizard`）新增对应提示。

### 7. `scripts/check_chapters.py` — 代价一致性检测（延后）

代价检测（"某角色使用了某层级能力 → 检查对应代价是否在正文中被体现"）是语义判断，当前 check_chapters.py 仅有结构性检查（frontmatter 字段/死角色/时空），无 NLU 能力。本计划**不做此修改**，记录为开放项，留待后续有 LLM 调用能力或更强关键词匹配方案时再评估。

## 评议修订记录

| 评议意见 | 处置 |
|---------|------|
| 代价检测不可实现（blocking） | 移除本计划，改为开放项 |
| 判据段在新模板中缺失 | 已补回——物理层末尾保留"判据：什么算硬核心"段 |
| 叙事层 vs 大纲主线来源表重叠 | 明确：核心设定.md 张力层为**权威源**，主线.md 的来源表仅做提问引导，不一致时以核心设定.md 为准 |
