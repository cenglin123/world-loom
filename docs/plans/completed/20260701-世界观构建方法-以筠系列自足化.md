## 3. 手册内容大纲（`00_世界观/_设计方法.md`）

> 每节结构统一：**一句话理念 → 可执行步骤 → 落到本仓库哪个文件**。以"能照着做"为准，不堆理论。**每模块约 200–400 字**（S5 用 `wc -m` 校验），既不失真也不膨胀。

- **#1 地图生成法**：随机碎裂（物理随机作种子）→ 地幔对流 → 山脉/河流 → 地形 → 文明选址。步骤化"如何从随机性生成一张自洽地图"。落点：`00_世界观/外围设定.md` 地理段。
- **#2 魔法/代价体系**：魔力网络（表面张力类比）+ 意识驱动 + **精神熵增作为核心代价**。步骤化"如何用『运作原理 + 代价』定义一套力量体系"（本仓已有魔力/功法，正好套用）。落点：`00_世界观/核心设定.md` 力量体系段。
- **#3 城镇选址评分法**：五维（水源/魔力网络/气候/资源/食物）打分 → 城镇 → 势力冲突 → 经典故事改编（"新瓶装旧酒"）。步骤化"如何用打分从地图长出城镇与势力"。落点：外围地理扩充。
- **#5 下水道视角**：水源与污秽处理 → 阶级 → 隐藏势力 → 边缘视角故事入口。步骤化"如何从底层反推整座城市 + NPC"。落点：城镇/NPC 细化。
- **#6 故事驱动法则**：一句指针 → `docs/writing-style.md` 「以筠·故事驱动法则」段（不重复）。
- **跨期主线**：一段"规则即土壤，世界自己长 + 代价比能力重要 + 从边缘看中心"的贯穿理念（来自系列索引），说明 #1→#2→#3→#5→#6 的搭建顺序。
- **知识库原文链接段**（末尾）：列出 #1/#2/#3/#5 对应知识库原文路径（`301【游戏娱乐】/…`）+ 系列索引，标注"完整方法与案例见此，本手册为可执行凝练"——满足 source_notes 可达性，读者需深挖时有去处。
