## 搭建顺序

地形生成 → 力量与代价 → 城镇选址 → 政权构建 / 组织建制 → 底层视角 → 故事驱动 → 反差身份。

- **物理层**（地形生成 + 力量与代价）：地形 + 能量网络 = 世界的硬件。
- **社会层**（城镇选址 + 政权构建 + 组织建制 + 底层视角）：地理与制度 → 阶级、职业、势力。
- **叙事层**（势力冲突 + 旧核新解 + 故事驱动法则）：设定失效 → 故事。
  六条故事驱动法则全文见 `docs/writing-style.md`。
- **角色层**（反差身份 + 反派设计）：世界规则落到个体——有人被逼抉择，故事才有"人"的落点。

三条贯穿理念：**规则即土壤，世界自己长** / **代价比能力更重要** / **从边缘看中心**。

## 引导对话原则

> Agent 在引导用户创建世界观/大纲/角色时，先探测用户当前模式（有限/无限），再调整引导策略。

**模式探测**（首次入口 2-3 轮内自然插入，不显式为问卷）：
- "你更想先把世界建完整再决定故事，还是已经有了一句话主线？"（目标明确度）
- "是更想多建一个城市/体系，还是更想写一小段场景？"（价值倾向）

**无限模式**（只想建世界玩）：苏格拉底式追问——"如果山在这里，这条河可能不会往那个方向流"；
帮世界跟用户抬杠。不催促、不要求取舍、不问"这对故事有什么用"。不触发推进剧情管道。

**有限模式**（想写完小说）：反向约束——"故事最少需要多少设定？"；用故事驱动法则反推。
提议切换时机：写不动 / 翻看设定 / 正文停滞 ≥2 轮。

**未确定模式**（探测 fallback，自主扩展）：默认假设有故事倾向但当前在探索。
以"这里有两种玩法——"开头让用户选；3 轮后无显式倾向则主动询问收束。
若收束询问后用户仍表示不确定，默认切换为有限模式引导——有限可以随时退到无限，
而反向则有设定不足的阻塞风险。

**Agent 内在自洽清单**（引导世界观时自然追问，不逐条念出）：

| # | 检查点 | 适用模式 |
|---|--------|---------|
| 1 | 物理层自洽——力量规则一致？无漏洞？ | 全模式 |
| 2 | 衍生自洽——社会层是物理层的自然衍生？ | 全模式 |
| 3 | 叙事空间——层间留够结构性矛盾？ | 有限/未确定 |
| 4 | 可推导性——底层规则允许自我演化？ | 全模式 |
| 5 | 故事自发性——角色在矛盾中自然产生故事？ | 有限/未确定 |
| 6 | 可解释性——角色行为能用设定完全解释？ | 有限/未确定 |
| 7 | 不割裂——力量使用的每次结果都能追溯到基本法则？ | 全模式 |

> 此清单是对三层架构（物理→社会→叙事）的补充扩展，与「规则即土壤」理念一致。
> 纯无限模式下跳过第 3/5/6 点。

**反差身份硬约束**（详见方法卡 `反差身份设计法`，此处只列引导行为）：
- 行为一贯性（全模式）：追问"两个矛盾行为是否源自同一深层动机？"
- 伏笔密度（有限模式）：反推"角色保守秘密时出现过哪些异常举动？"

**避坑**：纯推演世界连续 3 轮无故事/大纲/角色产出 → Agent 主动确认节奏是否满意；
有限模式下世界显贫瘠 → 主动提议"回头看看未深挖的设定，说不定能长出新故事线"。
