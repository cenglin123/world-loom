## #1 地图生成法 —— 随机碎裂 → 地形 → 文明

**一句话**：不手绘地图，用随机 + 地质规则让地形自己长出文明。

**步骤**：
1. **随机碎裂**取大陆/群岛雏形（"砸饼干"：想要群岛就碎得细，想要大陆就碎得粗）。
2. 在雏形上随手画**地幔柱与对流方向**：板块挤压线 = 山脉，拉扯线 = 裂谷。
3. 先定**特殊地形**（沙漠/高原/盆地/冰原）避免后期冲突 → 天然推出地势走向。
4. 沿地势画**河流**主干 + 支流；河流多寡 = 文明密度与村落合理性。
5. 描一圈**浅海**收边。
6. **命名**（山脉/大洋/洋流）+ **绑定种族与资源**：矮人守矿山 → 工业 + 沿海贸易；精灵居森林 → 神秘优雅。经济、文化、战争自然衍生。

**落点**：`00_世界观/外围设定.md` 地理段。

## #2 魔法 / 代价体系 —— 魔力网络 + 意识驱动 + 精神熵增

**一句话**：魔力分布用物理随机生成；力量体系的核心不是"能做什么"，而是"代价是什么"。

**步骤**：
1. **魔力网络**：把泡泡图（表面张力自动最小化能量）叠到地图 → 密集处魔力循环快、强魔文明、战争频；稀疏处稳定；交界线易起魔力风暴。可叠表层/深层两层（深层 → 特殊矿脉）。魔力是"像湿度一样看不见的环境属性"，靠周围人/物的反应感知。
2. **底层逻辑**：魔力 = 与未知沟通的桥梁，由**意识**驱动——"你认为它什么样就是什么样"；法咒 = 维持干净意识的口诀，法阵 = 固化的公式，无咏唱天才 = 意识更纯粹。
3. **核心代价（必设）**：施法 = 意识对外熵减 → 付出**精神熵增**（注意力涣散、记忆失真、分不清真实与想象）；器官 = 油箱、意识 = 引擎，过度施法伤器官，病变可生异种（如吸血鬼）。
4. 用"**运作原理 + 代价**"定义本仓已有的魔力/功法——代价越硬，设定越像真、越出故事（低魔比高魔更抓人）。

**落点**：`00_世界观/核心设定.md` 力量体系段。

## #3 城镇选址评分法 —— 打分选址 → 势力 → 新瓶装旧酒

**一句话**：用评分表科学选址，让城镇/势力/故事像齿轮咬合、自己转起来。

**步骤**：
1. **五维打分选址**：水源 / 魔力网络位置 / 气候带 / 资源矿脉 / 食物自给 → 推出城市规模与形态（如"近魔网但避汇集处 + 稳定河源"→ 数万人教会城）。
2. **气候铁律**：别把欧式繁复服饰搬到赤道——地理决定建筑、服饰、生活方式。
3. 给城市一个**核心势力 + 一个目标**（如教会：敛信徒、榨利、武力统治）→ 内部必有**裂痕**（纯信仰者 vs 借信仰谋利者），这不是 bug 是故事发动机。
4. **新瓶装旧酒**：取经典故事内核，用本世界规则重新解释（范海辛吸血鬼 → 魔力器官病变、只能吸血转移魔力；主角多重身份 = 前圣骑士团长 + 被教会背叛者 + 吸血始祖）。

**落点**：外围地理/势力扩充；与 `02_人物/` 人物卡衔接。

## #5 下水道视角 —— 从污秽反推城市与 NPC

**一句话**：城市真正的样子藏在下水道；问三个问题——"水从哪来 / 脏东西往哪去 / 谁有资格使用干净系统"，阶级、职业、势力、冲突自己浮现。

**步骤**：
1. **水从哪来 → 城市形态**：河流 → 沿河码头/渔市/染坊/商圈；井水 → 井是社区中心，谁控井谁控命脉；山泉 → 顺地势分层（上层饮头道泉、下层饮末水），**阶层自然生出**。
2. **脏东西往哪去 → 阶级显形**：神殿污水排下城、学院废液入地下水 = 现成冲突；卫生设施即阶级具象（贵族净化法阵 → 平民公厕 → 贫民窟即排污口）。
3. **"干净是被分配的资源"**：不公可以很安静——只是水流方向、街道坡度、一个排水口的位置。
4. **被忽视的职业 → 隐藏势力**：掏粪工/排水工/收尸队；下水道工会表面最底层，却握最全地下地图（暗渠通王宫/教会/港口）→ 地下黑市走私强权。可推演"工会罢工第 1/3/7/15 天"。

**落点**：城镇/NPC 细化；与 `02_人物/`、势力设计衔接。

## #7 角色反差身份 —— 表面身份 vs 秘密自我

**一句话**：角色魅力来自反差身份——表面身份 + 一个与之矛盾的秘密自我；反差不是搞笑梗，是逼角色做选择的冲突引擎。

**步骤**：
1. **四问框架**：① 表面身份是什么？② 它要求他必须怎样生活？③ 他真正想要的、害怕和隐藏的是什么？④ 哪天、什么事逼他必须在这两个自己之间做选择？
2. **质量标准**：反差必须**逼出选择 + 有代价**——为什么藏？被发现失去什么？为什么不能永远逃避？litmus test：能想象到角色的行动与故事，而非一个梗。
3. **行为一贯性 + 伏笔**：反差前后须共享同一行为逻辑（白天恶、晚上善不成立，除非给出原因，如长期压抑的释放）；反转前**必须铺伏笔**，越平淡越精彩——别提前把身份摊开。
4. **张力-克制**：张力（深层矛盾欲望）+ 克制（维持表面、防暴露）→ 平衡被意外打破 = 故事启动（主动追求：落差打破平衡；被动抉择：外部环境逼选）。
5. **反差被看见**：冲突不来自多重身份本身，而来自身份在**错误时间/空间被撞见**；根本是两个身份之间**有没有互相伤害、遮掩、逼迫**。

**落点**：`02_人物/人物模板.md`——表面身份（前史 + 可感知标签）vs 内核四维即反差两端；四问③/④映射内核与三档目标；行为一贯性由 L2 一致性审查兜、伏笔入 `04_伏笔/`。

## 跨期主线（搭建顺序 #1→#2→#3→#5→#6→#7）

- **物理层**（#1 #2）：地形 + 魔力网络 = 世界的硬件。
- **社会层**（#3 #5）：城镇选址 + 水源分配 → 阶级、职业、势力。
- **叙事层**（#3 #6）：势力冲突 + 新瓶装旧酒 + 设定失效 → 故事。
- **角色层**（#7）：世界规则落到个体——反差身份被逼抉择，故事才有"人"的落点。

三条贯穿理念：**规则即土壤，世界自己长** / **代价比能力更重要** / **从边缘看中心**。
