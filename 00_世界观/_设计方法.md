## 地形生成法

**一句话**：不手绘地图，用随机 + 地质规则让地形自己长出文明（随机碎裂 → 地形 → 文明）。

**步骤**：
1. **随机碎裂**取大陆/群岛雏形（想要群岛就碎得细，想要大陆就碎得粗）。
2. 在雏形上随手画**地幔柱与对流方向**：板块挤压线 = 山脉，拉扯线 = 裂谷。
3. 先定**特殊地形**（沙漠/高原/盆地/冰原）避免后期冲突 → 天然推出地势走向。
4. 沿地势画**河流**主干 + 支流；河流多寡 = 文明密度与村落合理性。
5. 描一圈**浅海**收边。
6. **命名**（山脉/大洋/洋流）+ **绑定人群与资源**：谁守着矿脉，谁就吃冶炼与军械（西幻的矮人、武侠的铁匠世家、科幻的采掘企业都一样）；谁占着林泽渡口，谁就吃商路与情报。经济、文化、战争自然衍生。

**落点**：`00_世界观/外围设定.md` 地理段。

## 力量与代价体系

**一句话**：力量分布用物理规则随机生成；力量体系的核心不是"能做什么"，而是"代价是什么"。

**步骤**：
1. **能量网络**：把泡泡图（表面张力自动最小化能量）叠到地图 → 密集处能量循环快、强力量文明、战争频；稀疏处稳定；交界线易起风暴。可叠表层/深层两层（深层 → 特殊矿脉）。力量是"像湿度一样看不见的环境属性"，靠周围人/物的反应感知。
2. **底层逻辑**：给力量一条可被角色理解的原理——例如"力量 = 与未知沟通的桥梁，由**意识**驱动，你认为它什么样它就是什么样"；由此推出**口诀**（法咒/心法/真言）= 维持干净意识的稳定器，**固化形制**（法阵/阵图/器械）= 把公式写死好让庸才也能用，**天才**= 不需要这些中介、意识本就更纯粹。
3. **核心代价（必设）**：动用力量 = 意识对外熵减 → 付出**精神熵增**（注意力涣散、记忆失真、分不清真实与想象）；肉身 = 油箱、意识 = 引擎，过度动用伤器官，病变者可生异种（西幻的吸血鬼、武侠的走火入魔者、仙灵的化魔者——同一条规则的不同外壳）。
4. 用"**运作原理 + 代价**"定义本书已有的力量/功法——代价越硬，设定越像真、越出故事（力量稀缺比力量泛滥更抓人）。

**落点**：`00_世界观/核心设定.md` 力量体系段。

## 城镇选址评分法

**一句话**：用评分表科学选址，让城镇/势力/故事像齿轮咬合、自己转起来。

**步骤**：
1. **五维打分选址**：水源 / 能量网络位置 / 气候带 / 资源矿脉 / 食物自给 → 推出城市规模与形态（如"近能量汇集处但不在正中 + 稳定河源"→ 一座数万人的圣城/宗门山城/要塞港）。
2. **气候铁律**：别把繁复厚重的服饰搬到赤道——地理决定建筑、服饰、生活方式。
3. 给城市一个**核心势力 + 一个目标**（教会敛信徒、宗门收灵材、藩镇征税、财团圈资源）→ 内部必有**裂痕**（纯信者 vs 借势谋利者、真传 vs 外门），这不是 bug 是故事发动机。
4. **旧核新解**：取经典故事内核，用本世界规则重新解释——例如"猎人反成怪物"的母题，在本世界可以是力量反噬导致的器官病变，于是主角同时是前执法者、被组织背叛者、和他毕生所猎之物的源头。换成任何题材外壳，内核不变。

**落点**：外围地理/势力扩充；与 `02_人物/` 人物卡衔接。

## 底层视角法

**一句话**：城市真正的样子藏在下水道；问三个问题——"水从哪来 / 脏东西往哪去 / 谁有资格使用干净系统"，阶级、职业、势力、冲突自己浮现。

**步骤**：
1. **水从哪来 → 城市形态**：河流 → 沿河码头/渔市/染坊/商圈；井水 → 井是社区中心，谁控井谁控命脉；山泉 → 顺地势分层（上层饮头道泉、下层饮末水），**阶层自然生出**。
2. **脏东西往哪去 → 阶级显形**：神殿/宗门/学院/工坊的废水排进下城或地下水 = 现成冲突；卫生设施即阶级具象（上层用净化手段 → 平民用公用设施 → 最底层住的地方本身就是排污口）。
3. **"干净是被分配的资源"**：不公可以很安静——只是水流方向、街道坡度、一个排水口的位置。
4. **被忽视的职业 → 隐藏势力**：掏粪工/排水工/收尸队；下水道工会表面最底层，却握最全地下地图（暗渠通王宫/教会/港口）→ 地下黑市走私强权。可推演"工会罢工第 1/3/7/15 天"。

**落点**：城镇/NPC 细化；与 `02_人物/`、势力设计衔接。

## 反差身份设计法

**一句话**：角色魅力来自反差身份——表面身份 + 一个与之矛盾的秘密自我；反差不是搞笑梗，是逼角色做选择的冲突引擎。

**步骤**：
1. **四问框架**：① 表面身份是什么？② 它要求他必须怎样生活？③ 他真正想要的、害怕和隐藏的是什么？④ 哪天、什么事逼他必须在这两个自己之间做选择？
2. **质量标准**：反差必须**逼出选择 + 有代价**——为什么藏？被发现失去什么？为什么不能永远逃避？litmus test：能想象到角色的行动与故事，而非一个梗。
3. **行为一贯性 + 伏笔**：反差前后须共享同一行为逻辑（白天恶、晚上善不成立，除非给出原因，如长期压抑的释放）；反转前**必须铺伏笔**，越平淡越精彩——别提前把身份摊开。
4. **张力-克制**：张力（深层矛盾欲望）+ 克制（维持表面、防暴露）→ 平衡被意外打破 = 故事启动（主动追求：落差打破平衡；被动抉择：外部环境逼选）。
5. **反差被看见**：冲突不来自多重身份本身，而来自身份在**错误时间/空间被撞见**；根本是两个身份之间**有没有互相伤害、遮掩、逼迫**。

**落点**：`02_人物/人物模板.md`——四问①/②写入「表面身份及其要求」，四问③拆入「秘密自我 / 错误信念 / 自觉欲望 / 深层需要」，四问④写入「逼迫选择的条件 / 暴露代价」；行为一贯性由当前稳定内核 + L2 审查共同保证，身份暴露伏笔登记到 `04_伏笔/`。

## 搭建顺序与贯穿理念

**顺序**：地形生成 → 力量与代价 → 城镇选址 → 底层视角 → 故事驱动 → 反差身份。

- **物理层**（地形生成 + 力量与代价）：地形 + 能量网络 = 世界的硬件。
- **社会层**（城镇选址 + 底层视角）：选址 + 水源分配 → 阶级、职业、势力。
- **叙事层**（势力冲突 + 旧核新解 + 故事驱动法则）：设定失效 → 故事。
- **角色层**（反差身份）：世界规则落到个体——反差身份被逼抉择，故事才有"人"的落点。

三条贯穿理念：**规则即土壤，世界自己长** / **代价比能力更重要** / **从边缘看中心**。

## 引导对话原则

> Agent 在引导用户创建世界观/大纲/角色时，先探测用户当前模式（有限/无限），再调整引导策略。框架来源：以筠「有限设计与无限设计」番外二（基于 James Carse《有限与无限的游戏》）。

**模式探测**（首次入口 2-3 轮内自然插入，不显式为问卷）：
- "你更想先把世界建完整再决定故事，还是已经有了一句话主线？"（目标明确度）
- "是更想多建一个城市/体系，还是更想写一小段场景？"（价值倾向）

**无限模式**（只想建世界玩）：苏格拉底式追问——"如果山在这里，这条河可能不会往那个方向流"；帮世界跟用户抬杠。不催促、不要求取舍、不问"这对故事有什么用"。不触发推进剧情管道。
**有限模式**（想写完小说）：反向约束——"故事最少需要多少设定？"；用故事驱动法则反推。提议切换时机：写不动 / 翻看设定 / 正文停滞 ≥2 轮。
**未确定模式**（探测 fallback，自主扩展）：默认假设有故事倾向但当前在探索。以"这里有两种玩法——"开头让用户选；3 轮后无显式倾向则主动询问收束。

**Agent 内在自洽清单**（引导世界观时自然追问，不逐条念出）：

| # | 检查点 | 适用模式 |
|---|--------|---------|
| 1 | 物理层自洽——力量规则一致？无漏洞？ | 全模式 |
| 2 | 衍生自洽——社会层是物理层的自然衍生？ | 全模式 |
| 3 | 叙事空间——层间留够结构性矛盾？ | 有限/未确定 |
| 4 | 可推导性——底层规则允许自我演化？ | 全模式 |
| 5 | 故事自发性——角色在矛盾中自然产生故事？ | 有限/未确定 |
| 6 | 可解释性——角色行为能用设定完全解释？ | 有限/未确定 |
| 7 | 不割裂——力量使用的每次结果都能追溯到基本法则？ | 全模式 |

> 此清单是对三层架构（物理→社会→叙事）的补充扩展，与「规则即土壤」理念一致。纯无限模式下跳过第 3/5/6 点。

**反差身份硬约束**（已纳入上文「反差身份设计法」，此处复述为引导行为）：
- 行为一贯性（全模式）：反差前后共享同一行为逻辑——追问"两个矛盾行为是否源自同一深层动机？"
- 伏笔密度（有限模式）：反转前必须铺伏笔——反推"角色保守秘密时出现过哪些异常举动？"

**避坑**：纯推演世界连续 3 轮无故事/大纲/角色产出 → Agent 主动确认节奏是否满意；有限模式下世界显贫瘠 → 主动提议"回头看看未深挖的设定，说不定能长出新故事线"。
